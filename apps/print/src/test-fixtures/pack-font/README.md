# report.woff2

A real font to stand in for the 27-byte placeholder `assets/report.woff2` of
T06's valid pack (`packages/template-tools/fixtures/valid`), so that pack can
be printed with its own font loaded. It is LXGW WenKai TC 1.530 Regular
(`public/fonts/LXGWWenKaiTC-Regular.ttf`, SIL OFL 1.1, `LICENSE-lxgw.txt`),
subset with `subset-font` 2 (harfbuzz) to the characters of that pack's
template and sample data, plus printable ASCII and `／：`, as woff2.
